## 문서 사이에서 어긋나거나 비어 있는 점

| # | 내용 | 근거 |
|---|---|---|
| 1 | 사장님 **방문 · 리뷰 리포트(S-07)**: 명세에는 남아 있지만 유저 플로우의 F-O2가 삭제됨. 와이어프레임 `owner-s04`, `owner-a03`(빈 상태)에는 남아 있음 | 변경 정리, 명세 S-07 |
| 2 | **빈 시간 달력**(`owner-s05`): D-02 삭제로 범위 밖 | 변경 정리 |
| 3 | S-03 "제휴 상점은 C-01 후보에서 우선" ↔ C-01 변경(제휴 여부를 추천 기준에서 제외)이 충돌 — 팀이 정리 예정 | 변경 정리 "확인할 점" |
| 4 | 와이어프레임 `guide-s04`의 "추천 상점 기준: 지역 데이터 점수 · 제휴 여부 · 리뷰 요약" 문구가 C-01 변경 전 기준 | 변경 정리 |
| 5 | ERD `users.name`은 NOT NULL인데 U-01 입력(이메일 · 비밀번호 · 역할)에 이름이 없음. 신청자 목록(A-04)은 이름을 보여줌 | ERD, 명세 |
| 6 | ERD `tour_wishes`(희망 탐방)에 대응하는 기능 · 화면이 없음 | ERD |
| 7 | ERD `tours`에 제목 · 학과 컬럼이 없음 — 화면의 탐방 제목은 대학교 + 가이드 학과로 조합해야 함 | ERD, 와이어프레임 |
| 8 | 보호자 동의 수단(이메일 링크 vs 문자)이 미정이지만 ERD는 `guardian_email`만 있음 | 명세 "구현 중 정할 것", ERD |
| 9 | 시연에서 운영자 심사를 보여줄지 미정 | 명세 "구현 중 정할 것" |
| 10 | 쿠폰 유효기간 = 탐방 당일(잠정). 본선 시연일(11/15)은 방학이 아니므로 시연용 탐방 날짜 · 시각 처리가 필요 | 명세 S-04, T-03 |
| 11 | `데이터 · API 설계` 페이지가 비어 있음 — API 명세 미작성 | 팀 홈 |
