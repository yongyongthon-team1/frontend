# 방학 상권 캠퍼스 탐방

방학 동안 대학 캠퍼스 주변 상권을 학생이 가이드와 함께 탐방하고, 코스 안의 제휴 상점에서 쿠폰을 쓰는 모바일 우선 웹 앱의 프런트엔드입니다.

## 시작하기

```bash
npm install
cp .env.example .env.local
npm run dev
npm run test:run
```

## 문서 위치

- `docs/superpowers/specs` : 설계 문서
- `docs/reference` : 기획 레퍼런스(기능 명세, ERD, 사용자 흐름, 와이어프레임)
- `docs/progress` : 진척 현황과 개발 기록
