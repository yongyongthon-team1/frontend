# 0010. 하이파이 디자인 V2(UNIRO)를 화면 기준으로 쓴다

- 날짜: 2026-11-06

## 맥락

11/5에 하이파이 시안 V2(브랜드 UNIRO · 41개 화면 · CMF 가이드)가 나왔다. 시안은 FigJam 보드에 있어 개발 도구(디자인 컨텍스트 · 변수 읽기)를 쓸 수 없었다. V2는 와이어보다 나중에 나왔고, 일부 화면은 구조(홈 입력, 코스 화면, 가이드 · 사장님 하단 탭, 신청 취소 확인)와 기능(사업자 심사, 알림 설정)까지 바꿨다.

## 결정

- FigJam 원본을 그대로 복사해 개발용 Figma Design 파일(https://www.figma.com/design/xNzkXH89Gc0bCbx8EYlBgk)을 만들고, 화면 · 토큰 · 문구 스냅샷을 `docs/reference/design-v2.md`와 `design-v2/*.png`로 남긴다.
- **V2가 있는 화면은 V2의 배치 · 문구 · 이동을 따른다.** 와이어보다 앞선다. V2에 없는 화면은 와이어의 기능 · 문구를 V2 시각 언어로 그린다. 기능 규칙은 설계 · 계약을 따르고, V2가 기능을 바꾸는 곳은 `design-v2.md`의 "V2가 바꾼 것" 표에서 하나씩 정한다.
- 토큰은 Design 파일 변수의 코드 이름(`--yy-color-*` 등)을 그대로 쓴다. 앱 글꼴은 V2대로 Noto Sans KR로 바꾸고 npm으로 번들한다(외부 CDN 금지는 그대로, 결정 0003의 Pretendard를 대체).
- MVP 2단계(P1 화면)는 와이어가 아니라 V2로 만든다. 골든 패스(P0) 화면도 V2로 다시 그린다 — 원래 3단계(11/9~12)의 하이파이 패스를 앞당긴다.

## 결과

화면을 두 번 만들지 않는다(와이어 버전 → 하이파이 버전). 대신 P0 화면을 다시 그려야 해서 골든 패스 · 무대 해상도 E2E를 새 배치로 다시 통과시켜야 한다. 무대 400px 예산(1단계 판정 C20)은 그대로 적용한다. 지도 유지 여부와 사업자 인증 방식은 팀 확인이 필요하다.
