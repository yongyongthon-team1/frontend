# 0009. main에 직접 커밋하고 푸시는 확인 후에 한다

- 날짜: 2026-11-03

## 맥락

이 레포는 사용자와 Claude만 작업한다. 브랜치와 PR을 거치면 해커톤 일정에서 시간만 든다. 한편 Vercel은 main 푸시를 프로덕션 배포로 취급하므로 푸시는 신중해야 한다.

## 결정

작업 단위마다 main에 바로 커밋하고, 메시지는 `feat|fix|test|docs|chore: 한국어 요약` 형식으로 쓴다. 푸시는 그때그때 사용자에게 확인받은 뒤에만 한다. 11/15 동결 절차에서는 14:30 프로덕션 동결, 스모크 테스트, 제출 커밋 태그를 거쳐 15:30 이후 문서 포함 모든 푸시를 금지한다.

## 결과

커밋은 로컬에 쌓이고 사용자가 확인한 때만 배포된다. 로컬 검사(typecheck · lint · test · build)를 통과한 커밋만 푸시한다. 진척 문서도 15:30 이후에는 커밋하지 않고, 회고는 시상식 뒤에 쓴다.
