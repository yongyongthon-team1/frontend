# 0004. 지도는 카카오맵을 쓰고 도식 지도로 폴백한다

- 날짜: 2026-11-03

## 맥락

코스 지도는 시연 골든 패스의 핵심 화면이다. 카카오맵은 국내 사용자와 심사위원에게 익숙하지만 JavaScript 키와 허용 도메인 등록이 필요하다. Vercel 프리뷰 URL은 배포마다 바뀌어 등록할 수 없고, 행사장 네트워크에서 SDK 로딩이 느리거나 실패할 수도 있다.

## 결정

`MapView` 하나로 감싸고 카카오맵 JavaScript SDK를 쓴다. 키가 없거나 SDK 로딩이 4초 안에 끝나지 않거나 `kakao.maps` 객체가 없으면 도식 지도와 지점 리스트로 자동 전환한다. 시연 패널에는 수동 토글도 둔다. 카카오에는 고정 프로덕션 도메인과 localhost만 등록하고, 외부 스크립트는 이 SDK 하나만 쓴다.

## 결과

지도가 안 떠도 코스 지점과 쿠폰 진입이 끊기지 않아 시연이 멈추지 않는다. 프리뷰 배포에서는 폴백이 보이는 것이 정상이다. 지도 검증 · 시연 · 제출은 고정 도메인에서만 한다. 카카오 키와 Vercel 고정 도메인은 팀 요청 16번으로 추적한다.
