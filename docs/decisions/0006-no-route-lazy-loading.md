# 0006. 라우트 단위 코드 분할(lazy)을 쓰지 않는다

- 날짜: 2026-11-03

## 맥락

화면이 40개 안팎이라 라우트별 분할로 얻는 이득이 작다. 반면 무대에서 역할을 바꿀 때 청크 로딩이 실패하거나, 재배포 뒤 옛 청크를 요청해 오류가 나면 2분 라이브 시연이 멈춘다.

## 결정

`React.lazy`와 라우트 `lazy`를 쓰지 않고 모든 화면을 정적 import한다. 예외는 `main.tsx`에서 목업 워커를 켤 때의 동적 import 하나뿐이다. 번들이 너무 커지면 첫 화면 뒤 전체 프리로드와, `vite:preloadError` 때 새로고침하는 방식으로 대응한다.

## 결과

첫 로드는 조금 무거워도 역할 전환과 화면 이동에서 네트워크 요청이 생기지 않는다. 이 규칙은 리뷰 기준에 올라 있다. 11/8 이후에는 의존성도 올리지 않는다.
