# 0011. 백엔드 API 명세와 T-01 희망 사항 흐름을 기준으로 삼는다

- 날짜: 2026-11-07
- 대체: 0010의 "V2가 있는 화면은 V2를 따른다"를 아래 우선순위로 좁힌다. `docs/api/frontend-needs.md`를 실제 계약으로 쓰던 것을 대신한다.

## 맥락

11/6에 백엔드 API 명세(노션 `API 명세서`, 46개 + 공통규칙)가 나왔다. 스냅샷은 `docs/api/backend-spec.md`다. 프론트가 만들어 온 계약(`frontend-needs.md`, 골든 패스 29개 동결 + P1 27개)과 비교하면 63쌍 중 그대로 맞는 것이 로그아웃 하나뿐이다. 대조는 `docs/api/backend-alignment.md`에 있다.

팀은 11/4 카톡에서 T-01을 바꾸기로 합의했다.
- AI 매칭을 하지 않는다. 학교 · 학과 칸과 희망 사항 한두 문장을 저장하고, 고교생이 입력한 원문을 그대로 보여 준다.
- 고교생의 "내 희망 사항" 화면과 대학생의 "학교 · 학과별 고교생 희망 사항" 화면을 더한다.
- 보호자 동의는 시연에서 생략하거나 '동의 완료'를 기본값으로 둔다.

11/7 기능 명세(노션)에 T-01 수정과 T-07 · T-08 추가가 반영됐다(`docs/reference/feature-spec.md`).

프론트의 2A 골든 패스는 문장 하나를 입력받아 AI 추천과 추천 이유를 보여 주는 화면으로 시작한다. 2B 계획(23개 태스크, 4개 완료)도 옛 계약 위에서 짜였다.

## 결정

- **충돌할 때의 우선순위.**
  1. 팀 합의와 기능 명세. 무엇을 만드는지 정한다.
  2. 백엔드 API 명세. API의 경로 · 요청 · 응답 모양을 정한다. 프론트가 맞춘다.
  3. V2 디자인. 배치와 시각을 정한다. 기능 명세와 다른 V2 화면(H01 홈 · H02 추천)은 V2 부품과 토큰으로 다시 그린다.
  4. 프론트가 썼던 계약 · 계획 · 판정. 위와 충돌하면 대체된다.
- **적용 방식은 혼합 어댑터다**(`backend-alignment.md` 7절).
  - 도메인 타입과 화면은 유지한다.
  - `features/*/api.ts`가 백엔드 경로를 부르고 `fromWire*` 어댑터로 바꾼다.
  - 봉투 벗기기 · snake/camel 변환 · 오류 코드 매핑은 `shared/lib/http.ts` 한 곳에서 한다.
  - 목업(MSW)도 백엔드 와이어를 낸다. 백엔드에 없고 시연에 필요한 값과 엔드포인트(시연 초기화 · 체크포인트 · 헬스 · 코스 지점 id · 쿠폰 방문 수 등)는 **목업 전용 선택 확장**으로 둔다. 어댑터는 확장이 없으면 대체 경로를 탄다.
- **T-01은 기능 명세대로 다시 만든다.**
  - 홈: 학교 · 학과 · 희망 사항 · 날짜(선택)를 입력해 저장한다.
  - 결과: 조건에 맞는 모집중 탐방 목록에 입력한 원문을 함께 보인다. 0건이면 같은 학교 모집중 탐방을 보인다.
  - AI 추천 관련 코드(목업 추천 AI, 추천 이유 · 관심 키워드 표시)는 지운다.
  - T-07 · T-08 화면을 더한다. V2 시안이 없으므로 V2 부품으로 그리고, 디자이너에게 공유할 메모를 남긴다.
- **시연에서 AI가 보이는 곳**은 C-01 코스 초안(과 리뷰 요약)이다.
- **무대 시연의 기본은 목업 모드다.** 시연 초기화 · 체크포인트는 기능 명세에도 백엔드에도 없다. 실서버 시연은 리허설로 확인한 뒤 `?mode=real`로만 쓴다. 실서버에 초기화가 없으면 패널이 초기화를 잠그고 사유를 보인다.
- **보호자 동의 시연 기본값.** 시연 계정은 동의를 끝낸 상태로 시드한다(지금과 같다). 가입부터 보여 주는 흐름이 생기면 시연 도구에서 '동의 완료'로 건너뛰게 한다.
- **`frontend-needs.md`는 기록으로 남긴다.** 맨 위에 "백엔드 명세로 대체됨"을 적고, 백엔드에 요청할 것만 `backend-alignment.md` 9절에 남긴다.
- **순서.** 백엔드 형식 전환과 T-01 흐름(MVP 2C)을 먼저 한다. 2B의 남은 태스크(T5~T23)는 2C 뒤에 백엔드 와이어 기준으로 다시 짠다. 기능 명세나 백엔드에 없는 화면은 뺀다. 2B T1~T4는 유지하고 T4의 가입 · 프로필 API만 백엔드 경로로 다시 맞춘다.

## 결과

- 골든 패스의 첫 장면이 바뀐다. 무대 점검 ①과 골든 패스 E2E의 대상이 "입력한 희망 원문 + 첫 탐방 행"으로 바뀐다. 단언을 느슨하게 하는 것이 아니라 대상 화면이 바뀐 것이다.
- 2A 판정 2A-R1 · R2 · R3(문장 하나 입력, 필터 칩, 추천 이유 줄)은 폐기된다.
- 목업과 실서버가 같은 와이어를 쓰므로, 백엔드가 뜨면 어댑터를 그대로 확인할 수 있다. 확장 필드는 백엔드에 요청할 목록 역할도 한다.
- 2B는 11/15까지 전부 끝내지 못할 수 있다. 2C를 마친 뒤 남은 시간에 맞춰 줄인다.
