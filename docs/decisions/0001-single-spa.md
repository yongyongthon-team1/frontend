# 0001. 로그인까지 포함해 React SPA 하나로 간다

- 날짜: 2026-11-03

## 맥락

사용자가 "SPA로, 보편적인 방식으로" 만들기를 정했다. 로그인 · 회원가입 · 보호자 동의 페이지만 Next로 따로 분리하는 안도 있었다. 분리하면 앱이 두 개가 되어 배포를 두 번 하고 로그인 상태도 공유해야 하는데, 해커톤 규모에서 얻는 것이 없다.

## 결정

고교생 · 가이드 · 사장님 · 운영자의 모든 흐름을 React SPA 하나에 담는다. 로그인 · 회원가입 · 보호자 동의 페이지(로그인 없이 열림)도 같은 앱의 라우트다. 기술 스택은 Vite + React 19 + TypeScript, React Router 7, TanStack Query 5, Tailwind CSS 4다.

## 결과

배포 단위가 Vercel 프로젝트 하나다. 세션 토큰과 쿼리 캐시를 한 앱 안에서 다루므로 역할 전환 때 캐시를 한 번에 비울 수 있다. 대신 SPA 새로고침 rewrite를 직접 챙겨야 한다(`vercel.json`).
