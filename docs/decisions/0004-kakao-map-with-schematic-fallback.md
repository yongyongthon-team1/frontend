# 0004. 지도는 카카오맵을 쓰고 도식 지도로 폴백한다

- 날짜: 2026-11-03

## 맥락

코스 지도는 시연 골든 패스의 핵심 화면이다. 카카오맵은 국내 사용자와 심사위원에게 익숙하지만 JavaScript 키와 허용 도메인 등록이 필요하다. Vercel 프리뷰 URL은 배포마다 바뀌어 등록할 수 없고, 행사장 네트워크에서 SDK 로딩이 느리거나 실패할 수도 있다.

## 결정

`MapView` 하나로 감싸고 카카오맵 JavaScript SDK를 쓴다. 키가 없거나 SDK 로딩이 4초 안에 끝나지 않거나 `kakao.maps` 객체가 없으면 도식 지도와 지점 리스트로 자동 전환한다. 시연 패널에는 수동 토글도 둔다. 카카오에는 고정 프로덕션 도메인과 localhost만 등록하고, 외부 스크립트는 이 SDK 하나만 쓴다.

## 결과

지도가 안 떠도 코스 지점과 쿠폰 진입이 끊기지 않아 시연이 멈추지 않는다. 프리뷰 배포에서는 폴백이 보이는 것이 정상이다. 지도 검증 · 시연 · 제출은 고정 도메인에서만 한다. 카카오 키와 Vercel 고정 도메인은 팀 요청 16번으로 추적한다.

## 구현

2026-11-04, Task 16. `src/features/courses/kakaoLoader.ts`가 SDK 스크립트(`autoload=false&libraries=services`)를 넣고 `kakao.maps.load` 콜백이 오면 성공으로 본다.

- 시간 제한은 4초(`KAKAO_LOAD_TIMEOUT_MS`)이고, 그 안에 콜백이 오지 않으면 실패(`TIMEOUT`)다. 스크립트 로드 오류나 로드 뒤 `kakao.maps`가 없는 경우도 실패(`LOAD_ERROR`)다.
- 로딩 결과는 실패까지 모듈에 기억한다. 스크립트는 세션당 한 번만 넣고, 실패한 뒤에는 새로고침 전까지 다시 시도하지 않는다. 시연 중에 지도가 떴다 안 떴다 하지 않게 하려는 것이다. 시간 초과 뒤에 스크립트가 늦게 떠도 `kakao.maps.load`를 부르지 않는다(쓰지 않을 지도 번들을 받지 않는다).
- `useKakaoMaps`는 키가 없거나 도식 지도를 강제하면 첫 렌더부터 도식 지도를 고른다. 이때는 스크립트를 넣지 않고 로딩 자리 표시도 거치지 않는다. 시연 패널의 수동 토글(지도 `자동` · `도식`)은 Task 21에서 `forceSchematic`에 연결했다.
- V2(2026-11-06, MVP 2A): 코스 화면의 첫 화면은 시간표이고, 지도는 시간표 아래 `지도로 보기` 펼침으로 옮겼다. `MapView`는 펼칠 때만 마운트하므로 열지 않으면 카카오 SDK를 부르지 않는다. 폴백 · 시연 패널 토글은 그대로다.
