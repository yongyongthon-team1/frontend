# 0003. 모든 스타일 값은 CSS 변수 토큰으로 정의한다

- 날짜: 2026-11-03

## 맥락

하이파이 디자인은 11/6쯤 오는데, 그 전에는 와이어프레임만 있다. 디자인이 오고 나서 컴포넌트마다 색과 간격을 고치면 11/12 기능 동결까지 시간이 모자란다.

## 결정

색 · 반경 · 간격 · 글자 크기 · 그림자를 모두 `src/styles/tokens.css`의 CSS 변수로 정의하고, Tailwind CSS 4 테마가 그 변수를 쓴다. 하이파이 전에는 중립 테마(Pretendard, 회색조 + 강조색 1개)로 시연 가능한 수준까지만 다듬는다. 폰트는 npm `pretendard`로 번들하고 외부 CDN은 쓰지 않는다.

## 결과

하이파이 반영이 토큰 값 교체, 컴포넌트 스타일 패스, 화면 패스 순서로 줄어들고, 골든 패스 화면부터 반영한다. 디자이너에게 토큰을 11/5까지 먼저 달라고 요청한다. 컴포넌트 코드에 색 값을 직접 쓰지 않는 규칙을 지켜야 한다.

11/6 V2 토큰 · Noto Sans KR로 교체(결정 0010). `--yy-*` V2 토큰을 추가하고 기존 의미 토큰은 V2 값으로 다시 묶었다.
