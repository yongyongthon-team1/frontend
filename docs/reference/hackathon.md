## 회의록 요점

- 10/28 첫 회의: 주제 **"방학 상권"**. 문제 가설 — 용인에 대학이 많아 대학 상권이 많은데, 방학이 되면 사람이 크게 줄어든다. 솔루션 — 방학에 상권을 살리기 위해 고등학생과 대학생을 연결해 학교를 소개하고 대학 주변을 소개하는 서비스. 남은 질문: 데이터로 증명 가능한가? 팀원 5명, 각자 트랙별 파트를 맡되 기획은 함께.
- 10/29 기획 구체화: 매칭(고등학생: 학과 · 하고 싶은 것 / 대학생: 학과) → 연락처 공유. 코스 짜기 = 데이터 + 대학생 의견 + 고등학생 '하고 싶은 것'. **코스는 이 웹에서 보여준다, 지도 기반으로 지점별 핀.** 프로모션: 코스 등록 상점 방문 시 할인(제휴). 방문 학생 그룹이 서비스 안에서 가게 리뷰.
