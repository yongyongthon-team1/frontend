# 유저 플로우 (스냅샷)

> 원본: 노션 `유저 플로우` — https://app.notion.com/p/409e0c1995d6805faa18f0bd722df914
> 스냅샷: 2026-11-03. **정본은 노션이다.**
> 순서도: 피그잼 "용용톤 user-flow" (왼쪽부터 공통(F-C0 · F-C1 · F-A1), 고교생, 대학생, 사장님. 노란색 = 다른 추천으로 돌아가는 분기, 빨간색 = 오류 · 취소, 초록색 = 완료)

각 단계는 '화면: 사용자 행동 → 시스템 반응 [기능]' 형식으로 적는다. 화면 이름은 공통 뼈대의 화면 목록, 기능 ID는 기능명세 탭과 같다. 분기 · 예외는 들여쓴 줄로 적는다.

## 목차
1. 공통 · 고교생 — F-C0 가입 · 로그인 (공통) / F-C1 역할을 인증한다 / F-H1 고교생이 탐방을 신청한다 / F-H2 고교생이 탐방 당일을 보낸다
2. 대학생 (가이드) — F-G1 가이드로 등록하고 탐방을 개설한다 / F-G2 신청자를 관리하고 코스를 확정한다
3. 사장님 — F-O1 가게를 등록하고 쿠폰을 처리한다 (F-O2 리포트·빈 시간 달력은 삭제됨)
4. 운영자 — F-A1 운영자가 인증을 심사한다

## 공통 · 고교생

### F-C0 가입 · 로그인 (공통)
1. 로그인: 이메일 · 비밀번호 입력 → 로그인 [U-02]
   - 분기: 계정 없음 → 회원가입
2. 회원가입: 이메일 · 비밀번호 · 역할(고교생 · 대학생 · 사장님) 선택 → 계정 생성, 역할 인증(F-C1)으로 [U-01]
3. 로그인 후 이동: 인증 전이면 역할 인증(F-C1), 인증 후면 역할별 첫 화면(고교생 홈, 대학생 신청자 관리, 사장님 내 가게, 운영자 인증 심사) [U-02]
4. 내 정보: (고교생) 학교 · 학년 · 관심 학과 입력, 인증 · 보호자 동의 상태 확인 → 홈 [U-03]

### F-C1 역할을 인증한다 (고교생 · 대학생 · 사장님)
1. 역할 인증 (고교생 · 대학생): 학교 선택, 학생증 또는 재학증명서 사진 업로드 → 상태 '심사중' [U-05]
   - 분기: 이미지 형식 · 용량 오류 → 다시 올리기
2. 역할 인증 (고교생): 보호자 이름 · 이메일 입력 → 보호자에게 동의 링크 발송 [U-06]
3. 보호자 동의 페이지 (보호자): 서비스 · 탐방 방식 안내 확인 후 동의 → '동의 완료' [U-06]
   - 분기: 동의 거부 · 링크 만료 → 고교생에게 다시 요청하라는 안내
4. 내 정보: 운영자 심사 결과 확인 → 승인되면 인증 배지, 반려되면 사유 확인 후 1단계로 [U-03, U-08]
5. 역할 인증 (사장님): 사업자등록번호 · 대표자명 · 개업일자 입력 → 진위확인 일치하면 '확인됨', 후보 상점 표시 → 내 가게 [U-07]
   - 분기: 불일치 · 휴폐업 → 재입력 안내

> 심사 중에도 홈 · 탐방 목록 둘러보기는 된다. 신청 · 개설 · 가게 연결은 인증이 끝난 뒤에 열린다.

### F-H1 고교생이 탐방을 신청한다
1. 홈: 관심 학과와 하고 싶은 것을 문장으로 입력, 학교 · 날짜는 선택 → AI가 추천 탐방 목록을 보여 준다 [T-01, D-01]
   - 분기: 추천 0건 → 같은 학교의 모집중 탐방 표시
2. 추천 탐방 목록: 탐방 카드(학교 · 학과 · 날짜 · 남은 자리 · 추천 이유) 선택 → 탐방 상세 [T-02]
3. 탐방 상세: 가이드 프로필 · 인증 배지 · 날짜 · 정원 · 소개 확인 후 신청 → 신청 완료 [A-01]
   - 분기: 재학 인증 · 보호자 동의 전 → '인증 후 신청할 수 있어요' 안내, 역할 인증(F-C1)으로
   - 분기: 정원 마감 → 신청 버튼 비활성, '다른 추천 보기' [T-01]
   - 분기: 이미 신청한 탐방 → '신청됨' 표시
4. 신청 완료: 상태 '신청' 안내 → 내 탐방 [T-04]
5. 내 탐방: 가이드가 승인하면 상태 '승인', 확정 정보와 오픈채팅 링크 공개 [T-04, A-02]
   - 분기: 거절 → 상태 '거절', 다른 탐방 추천으로 이동 [T-01]
   - 분기: 직접 취소 → 상태 '취소' [A-03]

### F-H2 고교생이 탐방 당일을 보낸다
1. 내 탐방: 코스가 확정된 탐방 선택 → 코스 지도 [C-04]
   - 분기: 코스 미확정 → '가이드가 코스를 준비 중' 표시
2. 코스 지도: 지점별 핀(순서 · 시간 · 상점 · 추천 이유 · 리뷰 요약) 확인 [C-04, R-02]
3. 코스 지도: 제휴 상점 핀에서 '쿠폰' → 쿠폰 (6자리 코드, 할인 내용) [S-05]
4. 쿠폰: 사장님에게 코드 제시 → 사장님이 입력하면 쿠폰이 '사용'으로 바뀜 [S-06]
   - 분기: 만료된 쿠폰 → '만료' 표시
5. 쿠폰 · 코스 지도: 쿠폰을 쓴 상점에 '리뷰 쓰기' → 리뷰 작성 [R-01]
   - 분기: 쿠폰을 쓰지 않은 상점 → 리뷰 버튼 없음
6. 리뷰 작성: 별점 · 한줄평 입력 → 저장, 가게별 AI 요약에 반영 [R-01, R-03]

## 대학생 (가이드)

### F-G1 대학생이 가이드로 등록하고 탐방을 개설한다
1. 가이드 프로필 등록: 학과 · 소개 입력 → 저장, 재학 인증이 승인되면 인증 배지 표시 [U-04]
2. 탐방 개설: 학교(인증된 학교) · 날짜 · 시간 · 정원 · 소개 · 오픈채팅 링크 입력 → 저장, 상태 '모집중' [T-03, D-01]
   - 분기: 재학 인증 승인 전 → 개설 불가 안내, 역할 인증(F-C1)으로
   - 분기: 방학 기간 밖 날짜 → 선택 불가 안내
   - 분기: 필수 값 누락 → 저장 불가
3. 신청자 관리: 개설한 탐방이 목록에 나타남 [T-04]

### F-G2 대학생이 신청자를 관리하고 코스를 확정한다
1. 신청자 관리: 탐방 선택 → 신청자 목록(이름 · 학년 · 하고 싶은 것) [A-04]
2. 신청자 관리: 신청자별 승인 / 거절 → 승인하면 그 신청자에게 오픈채팅 링크 공개 [A-02]
   - 분기: 승인 수가 정원에 닿으면 탐방 상태 '마감' [T-05]
   - 분기: 탐방 취소 → 신청자 모두에게 '취소' 표시 [T-05]
3. 코스 편집: '코스 만들기' → AI가 승인된 신청자들이 작성한 '하고 싶은 것'만을 기준으로 주변 상점과 매칭해 2~3시간 초안 생성 [C-01]
   - 분기: 승인된 신청자 0명 → 버튼 비활성
4. 코스 편집: 지점 순서 변경 · 상점 교체(주변 상점 지도에서 선택) · 한줄평 추가 [C-02, S-02]
5. 코스 편집: '코스 확정' → 승인된 신청자에게 코스 공개, 제휴 상점 쿠폰 자동 발급 [C-03, S-04]
6. 신청자 관리: 탐방이 끝난 뒤 '탐방 완료' → 상태 '완료', 신청자에게 리뷰 요청 [T-06]

## 사장님

### F-O1 사장님이 가게를 등록하고 쿠폰을 처리한다
1. 내 가게: 사업자 인증(F-C1)에서 찾은 후보 상점 중 내 가게 선택, 없으면 상호 검색 → 사장님 계정과 연결 [S-01]
   - 분기: 목록에 없음 → 직접 입력 (사업자 인증 전이면 역할 인증 F-C1로)
2. 내 가게: 제휴 할인 내용 · 기간 입력 → 제휴 상점으로 표시, 코스 추천 후보에 '제휴' 표시 [S-03]
3. 쿠폰 사용 처리: 학생이 보여 준 6자리 코드 입력 → 쿠폰 정보(할인 내용 · 탐방) 확인 후 '사용 처리' [S-06]
   - 분기: 다른 가게 쿠폰 · 이미 사용 · 만료 → 오류 안내

## 운영자

### F-A1 운영자가 인증을 심사한다
1. 로그인: 운영자 시드 계정으로 로그인 → 인증 심사 [U-02]
2. 인증 심사: 대기 목록(역할 · 학교 · 제출 시각)에서 요청 선택 → 학생증 사진 확인 [U-08]
3. 인증 심사: 승인 또는 반려(사유 입력) → 사용자 인증 상태 반영, 사진 파일 삭제 [U-08]
